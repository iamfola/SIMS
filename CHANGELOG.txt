CHANGELOG
==========

v5.2.0 - 2026-05-22
-------------------
Added:
  - Sidebar themes: light, glass, and colored variants configurable in school
    settings (sidebar_theme setting)
  - Secondary and accent CSS custom properties with dynamic light variants
  - Login page background themes (gradient, minimal) via login_bg_theme setting
  - Font family, border-radius, and footer text configurable in school settings
  - Custom CSS injection via school_settings.custom_css field
  - Dark mode colors now derived from school's secondary/accent colors

Fixed:
  - Dark mode white flash: added inline script in <head> that reads localStorage
    and sets data-bs-theme before page render, preventing white flash on
    navigation in dark mode
  - CSS: removed overlapping media queries at 575px that relied on !important
    (consolidated into existing breakpoints)
  - CSS: removed auto-animation from all .card elements to prevent layout shift
    on pages with many cards
  - CSS: removed stagger-children animation that caused staggered card entries
    on dashboards (felt sluggish)
  - CSS: improved .table-striped hover specificity by using direct child
    selectors (> tbody > tr) over tie-breaking source order
  - CSS: added prefers-reduced-motion query to disable animations for users
    with motion sensitivity
  - CSS: added :focus-visible outlines on .theme-toggle and .quick-action-item
    for better keyboard accessibility
  - CSS: replaced hardcoded color values with CSS custom properties (--primary,
    --secondary, --accent) throughout stylesheet for consistent theming

v5.1.3 - 2026-05-21
--------------------
Added:
  - Single session enforcement: logging in on a new device invalidates the
    previous session. Affected user sees "You have been logged out" message.
  - Mobile responsiveness: improved table scrolling, compact stat cards,
    and layout polish for very small screens

v5.1.0 - 2026-05-21
--------------------
Added:
  - Student PDF download: students can now download their result report card
    directly from the results page (GET /student/results/download)
  - Download PDF button on student results page alongside email option

v5.0.1 - 2026-05-21
--------------------
Fixed:
  - SendGrid email sending: sendResultPdfEmail now respects the email provider
    setting (was always using SMTP, ignoring SendGrid configuration)

v5.0.0 - 2026-05-21
--------------------
Added:
  - Version tracking: app version now displayed in the sidebar
  - CHANGELOG.txt: changelog file created to track changes

Fixed:
  - Admin dashboard: locked accounts counter now includes both OTP-locked and
    login-locked accounts (was only counting OTP lockouts, showing 0 when only
    login lockouts existed)
  - Admin sidebar: Locked Accounts moved into School Settings page as a section
    to prevent sidebar overflow on smaller screens; sidebar link now points
    to /admin/school-settings#locked-accounts
